This directory contains comprehensive Java examples illustrating core OOP concepts:

Encapsulation & Polymorphism: Real-world simulations like banking, ride-hailing, and library systems showcasing data hiding and method overloading/overriding.

Inheritance: Demonstrates single, multilevel, hierarchical, and hybrid inheritance through systems like schools, restaurants, and vehicles.

Java Classes & Constructors: Organized into levels with programs like Circle, Book, HotelBooking that show object creation, constructor overloading, and initialization logic.

Static, Final, This: Practical use of Java keywords in systems like hospitals and shops.

Object-Oriented Design: UML diagrams (class + sequence) for systems like e-commerce, hospitals, and universities to visualize OOP architecture.
